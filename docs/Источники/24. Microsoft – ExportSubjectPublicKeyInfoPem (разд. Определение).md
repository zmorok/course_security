Экспортирует часть открытого ключа текущего ключа в формате X.509 SubjectPublicKeyInfo в кодировке PEM.

```cpp

 System::String ^ ExportSubjectPublicKeyInfoPem();
```

```

```

#### Возвращаемое значение

[String](system.string)

Строка с кодировкой PEM X.509 SubjectPublicKeyInfo.

#### Исключения

[NotImplementedException](system.notimplementedexception)

Реализация для [ExportSubjectPublicKeyInfo()](system.security.cryptography.asymmetricalgorithm.exportsubjectpublickeyinfo#system-security-cryptography-asymmetricalgorithm-exportsubjectpublickeyinfo) или [TryExportSubjectPublicKeyInfo(Span&lt;Byte&gt;, Int32)](system.security.cryptography.asymmetricalgorithm.tryexportsubjectpublickeyinfo#system-security-cryptography-asymmetricalgorithm-tryexportsubjectpublickeyinfo%28system-span%28%28system-byte%29%29-system-int32@%29) не была предоставлена.

[CryptographicException](system.security.cryptography.cryptographicexception)

Не удалось экспортировать ключ.

## Комментарии

В кодировке PEM X.509 SubjectPublicKeyInfo начинается `-----BEGIN PUBLIC KEY-----` и заканчивается с `-----END PUBLIC KEY-----`содержимого DER в кодировке Base64 ключа между границами PEM.

```
          The PEM is encoded according to the IETF RFC 7468 "strict"
          encoding rules.
```
