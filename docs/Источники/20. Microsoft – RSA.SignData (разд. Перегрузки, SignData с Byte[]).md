```

#### Параметры

- data
    - [Byte](system.byte)[]

Входные данные для хэша и знака.

- hashAlgorithm
    - [HashAlgorithmName](system.security.cryptography.hashalgorithmname)

Хэш-алгоритм, используемый для создания хэш-значения.

- padding
    - [RSASignaturePadding](system.security.cryptography.rsasignaturepadding)

Режим заполнения.

#### Возвращаемое значение

[Byte](system.byte)[] 

Подпись RSA для указанных данных.

#### Исключения

[ArgumentNullException](system.argumentnullexception)

`data` равно `null`.

–или–

`padding` равно `null`.

[ArgumentException](system.argumentexception)

`hashAlgorithm`.[Name](system.security.cryptography.hashalgorithmname.name#system-security-cryptography-hashalgorithmname-name) is `null` или [Empty](system.string.empty#system-string-empty).

[CryptographicException](system.security.cryptography.cryptographicexception)

`padding` неизвестно или не поддерживается данной реализацией.

–или–

Этот экземпляр представляет только открытый ключ.

–или–

Произошла ошибка при создании подписи.
