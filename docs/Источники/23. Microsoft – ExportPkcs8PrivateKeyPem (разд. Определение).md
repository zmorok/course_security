Экспортирует текущий ключ в формате PKCS#8 PrivateKeyInfo, закодированный PEM.

 System::String ^ ExportPkcs8PrivateKeyPem();
```

```

#### Возвращаемое значение

[String](system.string)

Строка, содержащая PKCS#8 PrivateKeyInfo с кодировкой PEM.

#### Исключения

[NotImplementedException](system.notimplementedexception)

Реализация для [ExportPkcs8PrivateKey()](system.security.cryptography.asymmetricalgorithm.exportpkcs8privatekey#system-security-cryptography-asymmetricalgorithm-exportpkcs8privatekey) или [TryExportPkcs8PrivateKey(Span&lt;Byte&gt;, Int32)](system.security.cryptography.asymmetricalgorithm.tryexportpkcs8privatekey#system-security-cryptography-asymmetricalgorithm-tryexportpkcs8privatekey%28system-span%28%28system-byte%29%29-system-int32@%29) не была предоставлена.

[CryptographicException](system.security.cryptography.cryptographicexception)

Не удалось экспортировать ключ.

## Комментарии

PKCS#8 PrivateKeyInfo в кодировке PEM начинается `-----BEGIN PRIVATE KEY-----` с и заканчивается с `-----END PRIVATE KEY-----`содержимого DER в кодировке Base64 ключа между границами PEM.

```
          The PEM is encoded according to the IETF RFC 7468 "strict" encoding rules.
```
