# Назначение и ответственности основных классов системы

Архитектура программного средства построена на принципе единственной ответственности (Single Responsibility Principle) для обеспечения модульности и наглядности при защите курсового проекта:

* **`DocumentData`** — доменная модель документа (номер, владелец, даты). Не содержит криптографической логики. Выполняет базовую валидацию корректности заполнения реквизитов.
* **`SignedPayload` / `UnsignedPayload`** — транспортные модели протокола. `UnsignedPayload` объединяет поля, подлежащие канонизации и подписанию. `SignedPayload` добавляет вычисленную цифровую подпись.
* **`PayloadCanonicalizer`** — протоколообразующий класс. Приводит данные к единственному строго детерминированному представлению байт UTF-8 для обеспечения воспроизводимости подписи на любых платформах.
* **`PayloadCodec`** — стандартная транспортная сериализация и десериализация полного JSON-контейнера.
* **`Base64Url`** — кодирование двоичной цифровой подписи и зашифрованного контейнера в текстовую строку без спецсимволов (`+`, `/`, `=`), безопасную для URL и QR-сканеров.
* **`FeistelCipher`** — собственный 128-битный симметричный блочный шифр на базе классической сети Фейстеля (16 раундов, 8-битный нелинейный S-box, диффузионная раундовая функция с золотым сечением и циклическими сдвигами, режим CBC с криптографическим вектором инициализации IV и выравниванием PKCS#7). Обеспечивает конфиденциальность данных документа.
* **`PayloadEncryptionService`** — оркестратор шифрования и расшифрования транспортных контейнеров QR-кода (`ENC1.<base64url>`). Управляет симметричным мастер-ключом приложения, преобразует открытый JSON в непроницаемый для внешних сканеров шифротекст и обратно, гарантирует обратную совместимость с открытым форматом.
* **`KeyManager`** — генерация асимметричных ключей RSA (2048/3072 бит), экспорт и импорт в стандартных форматах PEM (PKCS#8 и SPKI), а также расчет открытого отпечатка ключа `kid` (Key ID).
* **`TrustedKeyStore`** — граница модели доверия. Хранит исключительно явно импортированные открытые ключи доверенных издателей. Пресекает атаки с подменой ключа.
* **`SignatureService`** — стандартная криптографическая обертка над алгоритмом RSA-PSS с хешированием SHA-256 (`System.Security.Cryptography`).
* **`PayloadCreationService`** — оркестратор жизненного цикла создания: реквизиты -> вычисление `kid` -> канонизация -> формирование подписи RSA-PSS -> упаковка в JSON -> (опционально) симметричное шифрование Feistel-128-CBC.
* **`AuthenticityVerifier`** — оркестратор верификации: распознавание зашифрованного контейнера `ENC1` -> расшифрование Feistel-128 -> парсинг -> проверка версии и алгоритма -> поиск доверенного ключа по `kid` -> проверка подписи над каноническими байтами -> контроль срока действия.
* **`QrCodeService`** — оптический кодек (генерация матриц с уровнями коррекции Рида-Соломона L/M/Q/H и декодирование растра через ZXing.Net). Не зависит от криптографии.
* **`ImageDistortionService`** — экспериментальное моделирование оптических и физических дефектов (поворот, пятна, шум, расфокусировка, сжатие).
* **`ExperimentRunner`** — автоматический запуск серийных измерений устойчивости с фиксацией seed для воспроизводимости.
* **`StatisticsService`** — агрегация статистических метрик и экспорт данных в CSV для расчетно-пояснительной записки.
