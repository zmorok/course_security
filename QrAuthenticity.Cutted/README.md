# QrAuthenticity.Cutted

Отдельное WPF-приложение в решении `QrAuthenticity.sln` для создания и чтения зашифрованных QR-кодов.

Оставлены две вкладки:

1. **Создание QR-кода**: реквизиты документа, коррекция ошибок L/M/Q/H, симметричный ключ, просмотр зашифрованных и расшифрованных данных, сохранение PNG.
2. **Проверка QR-кода**: загрузка изображения или вставка текста, использование QR с первой вкладки, расшифрование и вывод реквизитов.

Алгоритм шифрования — существующий собственный Feistel-128-CBC с IV и дополнением PKCS#7. Для чтения требуется тот же симметричный ключ, который использовался при создании. Ключ вводится в каждой вкладке; кнопка «Сброс» возвращает значение по умолчанию. Локальное хранилище ключей отсутствует.

## Формат данных

В QR записывается `ENC1.<Base64Url(IV + Ciphertext)>`. Внутри зашифрован следующий JSON:

```json
{"v":2,"data":{"document":"DOC-123","owner":"Иван Иванов","issued":"01.10.2026","expires":"01.10.2031"}}
```

`expires` может быть `null`. Версия 2 отличает этот контейнер от подписанного контейнера полной версии. Старые подписанные QR-коды и открытый JSON не принимаются. Полная версия также не читает новый формат без отдельного расширения поддержки.

Сообщение «Данные расшифрованы» означает успешное чтение и проверку структуры данных. Цифровая подпись, подтверждение авторства и защита от изменения данных в этом приложении отсутствуют. Дата окончания выводится как реквизит и не блокирует чтение.

## Сборка и запуск

Требуются Windows и .NET SDK 10 или новее. Из каталога решения:

```powershell
dotnet build QrAuthenticity.sln -c Release
dotnet run --project QrAuthenticity.Cutted/QrAuthenticity.Cutted.csproj
dotnet test QrAuthenticity.Cutted.Tests/QrAuthenticity.Cutted.Tests.csproj
```

В Visual Studio выберите `QrAuthenticity.Cutted` как запускаемый проект. Приложение имеет обычные конфигурации `Debug` и `Release`.

## Общие исходные файлы

В `.csproj` подключены как ссылки только `DocumentData`, `QrCodeService`, `FeistelCipher`, `PayloadEncryptionService`, `Base64Url` и конвертеры дат. Ссылки на сборку полного приложения нет: код RSA, цифровой подписи, доверенного хранилища, атак и экспериментов не включается в исполняемый файл Cutted.
